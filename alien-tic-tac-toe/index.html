How to play

  1. Pick an empty square. The board locks while you battle for it.
  2. Counter the alien’s move: Laser → Shield, Shield → Blast, Claw → Dodge.
  3. A correct response takes one alien health. A wrong response costs you one health. Each starts with 2.
  4. Win the fight to place X. Lose it and O takes that square. There is no automatic alien move.
  5. Three X in a line wins; three O in a line wins for the aliens. A full board with no line is a draw.

Restart game clears the entire board and any fight in progress.
